vai criar uma pasta no seu pc com esse nome dentro da pasta do projeto

abre ela, coloca as duas planilhas dos questionários q tão no drive q eu mandei no gp

no cando direito em cima do rstudio vai na aba git, clica em push pra pegar as alterações recentes
